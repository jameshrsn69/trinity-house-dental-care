# Trinity House Dental Care

Trinity House Dental Care is a dental practice in Wilmslow, Cheshire. The practice offers general dentistry, cosmetic treatments such as teeth whitening, veneers and composite bonding, orthodontics including Invisalign, and restorative care including dental implants.
